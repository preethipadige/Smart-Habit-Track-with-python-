# Smart-Habit-Track-with-python-
A Python-based habit tracking application with a graphical interface built using Tkinter. It helps users build consistency, track streaks, and earn reward points for completing daily and weekly habits.

How It’s Programmed
- Object-Oriented Design
- Habit base class defines common attributes (name, frequency, streak).
- daily_Habit and weekly_Habit subclasses extend functionality with different reward systems.
- User class manages habits, points, and completion logic.
- Reward System
- Daily habits: 10 × streak points.
- Weekly habits: 20 × streak points.
- GUI with Tkinter
- Buttons for each habit.
- Labels for streak updates, points, and user messages.
- Color-coded interface for clarity and motivation.
- Datetime Integration
- Tracks when habits are completed using Python’s datetime module.
